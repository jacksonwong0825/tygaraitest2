# Tygar AI Official Website

This repository contains the full static website source code for **Tygar AI**.

## Structure
- `index.html`: The main website file containing full layout, responsive styling (Tailwind CSS), and scripts.
- `assets/`: Directory for static assets like images, logos, and icons.

## Deployment on GitHub Pages
1. Upload all contents of this repository/zip to your GitHub repository.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Choose Branch: `main` / Folder: `/ (root)` and click **Save**.
